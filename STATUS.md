## How to run the checks

- Installers: `packaging/package_linux.sh --build` makes the .deb and .rpm in `dist/` (needs podman and nfpm); Windows: `packaging/build_windows.ps1` on the Windows computer; see `packaging/PACKAGING.md`.

- Run only the tests related to a change, never the full suite (owner's instruction): `.venv/bin/pytest <test files>`, then `.venv/bin/pyrefly check --min-severity warn`, the same with `--python-platform win32` (what the Windows computer sees), and `.venv/bin/lint-imports`. The interface tests need no screen (Qt offscreen).
- Against the real server: `.venv/bin/pytest -m live` (needs `tests/live/account.local.toml`, see `account.example.toml`).
- Real credential store (creates and removes one entry in the owner's wallet): `.venv/bin/pytest -m oskeyring`.
- 500,000-message performance test (about an hour, 3 to 4 GB in `~/chrono-mail-perf`): `.venv/bin/pytest -m perf -s`.
- The command line: `.venv/bin/chrono-mail-cli --help`; `--json` for machine-readable output; secrets only through `--<name>-stdin`; commands that delete need `--yes`.
