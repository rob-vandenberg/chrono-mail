# Recovery code shown until stored
Topics: [[storage]] · [[security]] · [[mail-window]]

(batch 5, RV-03, RV-77) **A new data key's recovery code is shown until the person confirmed it is stored**, remembered through a restart; a restore goes on only after it. A drag of messages of several accounts goes to no folder; nothing moves halfway without a word. Why: a restore stopped at the code, or Cancel during Add account, made the key and never showed its code again.
