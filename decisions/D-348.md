# A server's lasting "no" to an item is said once; a passing failure of Google's colours is said only when it lasts
Topics: [[calendars-contacts-tasks]] · [[basic-rule]]

(the owner) **An item a server lists but refuses to hand out for good is remembered and said once;** it is asked for again only when it changes on the server, and once at every start of Chrono Mail. **A passing failure while reading Google's event colours shows nothing;** only at the third synchronisation in a row it is said once, calmly; a refusal of Google still shows at once. Why: the same message at every Refresh alarms and tells nothing new (Kerio's Public Contacts; a broken-off connection to Google).
