# An account is a faithful copy
Topics: [[basic-rule]] · [[imap]] · [[calendars-contacts-tasks]] · [[sync-conflicts]]

(the owner) **An account is a faithful copy of the account on its server** (IMAP, CalDAV, CardDAV). The full rule is AGENTS.md §0: server first, here only when it confirms; offline done here, remembered, sent later; a lasting refusal is a sync conflict, a passing failure is retried; two computers end up the same; exceptions: local data, POP3, and local-only data the owner approved ([[D-172]], [[D-191]], [[D-201]]). Every changelist says how it keeps the rule.
