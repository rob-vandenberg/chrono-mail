# Send locks in one order
Topics: [[pop3-smtp-sending]]

(the re-check of the review, RV-178 to RV-184) **The send locks come in one order, the mailbox first**: open the mailbox, then the repeat lock, then the Outbox lock. A message the server took moves only to Sent, Trash or back to the Outbox, and never becomes a draft. A scheduled message is sent only when it was still in Scheduled at that moment. Why: each of these sent a message twice, sent one that was withdrawn, or froze the program.
