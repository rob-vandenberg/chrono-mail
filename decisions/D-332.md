# One list of tags, each shown in the sections chosen
Topics: [[tags]] · [[calendars-contacts-tasks]] · [[look]]

(the owner) **There is one list of tags; each tag has one name, one colour and one shortcut, and Show in ticks for Mail, Calendar, Contacts and Tasks. Settings > Tags shows that one list, edited on its own lines: the name in its colour (renamed in place), a colour square, the four ticks, a shortcut drop-down (Not assigned, or one no other tag has), ✕; Add tag adds a line, a line is dragged to its place.** A section offers only the tags shown in it; an item keeps a tag it carries. Contacts and tasks get the appointment window's Tags box, without radio buttons. Why: the Tag overview ([[D-328]]) needs one tag across sections, and a section should not offer tags meant for another; tabs over one list hid that the list is one.
