# The folder list is built once
Topics: [[changes-reach-the-screen]] · [[mail-window]]

(R-11) **The folder list is built once and never again**: it works out what should be there and adds, removes, moves or changes only the entries that differ, each known by its key, so the selection, open branches and scroll stay by themselves. When the selected entry goes, its account's Inbox is selected. No guard flags, nothing put back by hand.
