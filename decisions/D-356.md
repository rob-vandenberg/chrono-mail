# A server name never has an @
Topics: [[calendars-contacts-tasks]] · [[sync-conflicts]]

(the owner) **An appointment, task or contact Chrono Mail puts on a CalDAV or CardDAV server gets a name without an @**; its identifier inside stays as it is. **Its own items an older version named with an @ are renamed once, on the server first** (WebDAV MOVE, D-193): the link follows only when the server confirms; a passing failure is tried again; a server that does not rename (405, 501) or forbids it (403) is not asked again; an item already gone or a name taken (404, 409, 412) skips that item only. Another computer follows such a rename without a delete or a conflict (4.4.625). Why: another program's later syncs skip an item whose server name has an @, so Chrono Mail's appointments showed only after re-adding the account (proven on the Kerio test account, 2026-11-18).
