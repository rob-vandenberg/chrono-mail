# Order in which Mail's toolbar folds
Topics: [[look]]

(the owner) **Mail's toolbar gives way in this order**: Delete, Move to, Snooze, Archive, Tag and Mark fold into More (right-most first), then the search field's "All folders" shows only its ▾, then Forward, Reply all and Reply, then Refresh and New; the search field shrinks last; Menu never goes. Why: the reply buttons and where the search looks are used more than the rest.
