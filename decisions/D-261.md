# A restore touches only what it set aside
Topics: [[storage]] · [[imap]]

(RV-193 to RV-199) **A restore never touches more than it set aside, and names only what came back**: when setting this computer's data aside stops half-way, nothing is moved or removed; a restored account names only the messages that came back, so the others are downloaded again, never deleted on the server. Why: a failed restore could delete all mail, and a restore could have mail deleted on the server.
