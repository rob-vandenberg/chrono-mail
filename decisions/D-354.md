# The default font of new messages
Topics: [[mail-window]] · [[look]]

(the owner) **Settings > Writing > Default font**: a font and a size in points. New messages are written in it, and every HTML message carries it, so the receiver sees what the sender saw and not the serif default of a reading program. Not chosen, it is the program's own font at the system's size, and keeps following them. The size slider only enlarges what the writer sees. Why: a person's complaint that sent mail arrived in a serif font, with no way to change it.
