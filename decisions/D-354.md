# The default font of new messages
Topics: [[mail-window]] · [[look]]

(the owner) **Settings > Writing > Default font**: a font and a size in points. New messages are written in it, and every HTML message carries it, so the receiver sees what the sender saw and not the serif default of a reading program. Not chosen, it is the program's own font at the system's size, and keeps following them. A chosen font this computer does not have stays the choice: it shows its name with "(not installed)", is never replaced by the font Qt draws in its place, and is used again once installed. The size slider only enlarges what the writer sees. Why: a person's complaint that sent mail arrived in a serif font, with no way to change it.
