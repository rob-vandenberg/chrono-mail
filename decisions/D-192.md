# Collection name and colour from the server
Topics: [[calendars-contacts-tasks]] · [[sync-conflicts]]

(R-26, R-27, the owner) **A server collection's name and colour follow [[D-193]]**: changed on the server first, taken from it at every sync. What Chrono Mail holds differently (waiting or refused) is kept with the account, so it survives untick and re-tick. A clash or a lasting refusal of a name is a sync conflict. Read-only: Rename and Colour greyed.
