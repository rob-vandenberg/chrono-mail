# Dialogs from Qt Designer forms
Topics: [[mail-window]] · [[look]]

(the owner) **Every dialog is built from a Qt Designer form** (`ui/forms/*.ui`; not the main window, the composer, the message window, the parts the program draws, Qt's own boxes and pickers). A form holds the parts, their texts, order, layout, spacing and a window's title, nothing else: no colours, styles, fonts or fixed sizes (a test refuses them); the program adds values, the sizes at the size factor and the look. Why: the owner designs a dialog in Designer, and the program shows exactly that.
