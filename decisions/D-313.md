# D-313 Reminders fire from Chrono Mail
Topics: [[calendars-contacts-tasks]]

(The owner) An event has at most 5 reminders, each Notification or Email, stored in the event as VALARM. Chrono Mail fires them itself while it runs and mails Email reminders to your own address; notifications are always Chrono Mail's. Per account, on each computer: Send reminder emails via Chrono Mail or Server, or the box off, so a person with two computers lets one send; default Chrono Mail, greyed only when certain. What a person chooses for the server is their own responsibility. A task's reminder fires the same way (D-316).
