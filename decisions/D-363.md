# The bar of the New message window follows the reference client
Topics: [[mail-window]]

(the owner) **Above the text, in rich and in plain text: the paperclip (attach), Signature (the text put in as the signature, replacing the one there), Template (the same list, the text added at the cursor), B, I, U, Paint Format (the look of the selected text given to the next text selected with the mouse), Font Style (the A: font, size, Text Color and Background Color, each a grid with Custom color…, the background also No color), the lists; at the right the three dots: Save, Format (Rich text or Plain text), Cut, Copy, Paste, Remove Format, Undo, Redo, Outdent, Indent, Insert Link, Insert Image.** In plain text what only rich text can do is greyed; Attach a file…, Plain text and Signature below the text are gone, Remove stays; the window of one text in Settings > Templates and Signatures has the same formatting, not the message's buttons. Why: the owner, "Look at the toolbar, ours need to be the same" ([[D-358]] for the two buttons).
