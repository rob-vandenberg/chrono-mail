# Only what a person sees conflicts
Topics: [[calendars-contacts-tasks]] · [[sync-conflicts]]

(the owner) **Only what a person enters or sees makes a sync conflict**: the fields Chrono Mail's own windows show; any other difference (ids, counters, stamps, Private, an attendee's answer, other programs' markers) takes the server's version without a word. Every difference is a choice, nothing chosen beforehand; Use Chrono Mail is every difference to Chrono Mail, field by field; Use Server data stays the server's whole version. Why: two choices that look the same, or raw calendar values, tell a person nothing.
