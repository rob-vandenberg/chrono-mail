# Google event colours through Google's Calendar API
Topics: [[calendars-contacts-tasks]] · [[tags]] · [[basic-rule]]

(the owner, ROADMAP 5.4) **An event in a Google calendar shows the colour Google gives it when it has no tags, and a changed colour tag is sent to Google** as the nearest of Google's eleven colours (no tag left: the calendar's own colour), on Google first ([[D-193]]). Google's CalDAV does not carry an event's colour, so Chrono Mail reads and sets it through Google's Calendar API with the same sign-in ([[D-335]]); the colours are kept on this computer beside the items and never written into an event's text. The tag still decides the colour here ([[D-329]]); a tag an event had before is never sent, a calendar the API does not know (Google's holiday calendars) has no colours. Why: what the person coloured on Google's website should look the same here, and a colour chosen here should reach the website and the other computers.
