# A new key never cuts off Local Folders
Topics: [[storage]] · [[security]]

(the owner) **Local Folders kept here is never cut off by a new key**: no new key is made while it needs its own; written with an older key this computer still has, it is written again with this computer's key; when that key is gone for good, it is set aside, never deleted. Why: adding an account first made a new key, and that mail could never be opened again.
