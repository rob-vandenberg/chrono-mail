# Remove from Unread when marked read
Topics: [[changes-reach-the-screen]] · [[mail-window]]

(the owner) **Settings > Message list: "Remove messages from Unread when I mark them as read"**, off by default. On, the person's own Mark as read in a list of only unread mail takes the messages out as Junk does ([[D-266]], [[D-267]]). A message read by showing it stays (it would vanish while being read). Kept on this computer only.
