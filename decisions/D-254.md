# Edits never lose hidden data
Topics: [[calendars-contacts-tasks]]

(RV-16, RV-17) **An edit of a contact or an event never loses what the window does not show**: a birthday without a year is shown and kept, and the birthday is sent only when it was changed; attendees given again keep their names, roles and answers. Why: any Save removed such birthdays and reset every attendee's acceptance, on the server too.
