# The Calendar's Tags list holds only the tags of the ticked calendars
Topics: [[tags]] · [[calendars-contacts-tasks]]

(the owner) **In Calendar, the Tags list shows only the tags in use in the ticked calendars**, a Google calendar's own and the person's alike, and its numbers count only their appointments; unticking a calendar takes away the tags only it uses, nothing ticked leaves the list empty. A tag filter whose tag goes with an untick goes off, and every appointment of the ticked calendars shows. Why: "if the Esther calendar is unticked, they are meaningless."
