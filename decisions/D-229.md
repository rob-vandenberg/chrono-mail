# Index rebuilds at start
Topics: [[storage]]

(the owner) **Index rebuilds at start**: every index is checked before the mail is shown; unusable ones are rebuilt one after the other in a window with progress, and the mail checks wait meanwhile. An older index that can be upgraded in place is usable at once, what it lacks filled in afterwards in the background. The mail is never touched; the old index stays in use until the new one replaces it.
