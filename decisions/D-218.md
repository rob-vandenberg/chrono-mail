# One way to hold every view
Topics: [[changes-reach-the-screen]] · [[mail-window]]

(R-15) **The message list holds every kind of view one way**: the order of every message of the view (one answer of the engine) and the rows loaded so far, asked by the message, never by place. The count line and scrollbar count the whole view at once. An action takes every selected message, loaded or not (its place comes from the order). One queue runs actions, drops, the Delete icon and Undo presses in the order made.
