# Mail refusals are sync conflicts
Topics: [[imap]] · [[sync-conflicts]]

(R-24) **Mail refusals are sync conflicts; marks never clash.** Marks are compared one at a time against the agreed marks, so both sides cannot clash. A lasting "no" to a change made offline is a sync conflict and is not sent again while open: marks refused (Use Server data), a move refused (Use Server data moves it back), a message or folder made here and refused (Keep here only; the server's side is never offered).
