# Every action on the server first
Topics: [[imap]]

**Every action of the person** (marks, move, copy, archive, junk, snooze, delete, empty, drafts, the Sent copy, rules) **is done on the server first**, by UID, and here only after it confirms; a refusal changes nothing here. Offline: done here, sent later by [[D-050]]. Without MOVE: copy then remove by UID. An expunge never removes more than the messages named; without UIDPLUS it refuses. Servers without UIDPLUS are not supported.
