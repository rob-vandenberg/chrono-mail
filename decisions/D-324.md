# An appointment's title is edited in place
Topics: [[calendars-contacts-tasks]] · [[changes-reach-the-screen]]

(the owner) **In the Day, Week and Month views a click on the selected appointment, or F2, makes its title editable where it is drawn**; Enter or a click elsewhere saves, Escape does not, an empty or unchanged title saves nothing. Only the title changes, on the server first, of this date only for a repeating appointment, and Chrono Mail mails no one (a server that mails attendees by itself may). Not for the Agenda, a read-only calendar, a Cancelled or a declined appointment. Why: renaming an appointment should not need the editor window.
