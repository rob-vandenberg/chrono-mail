# Standard folder names, one language
Topics: [[importer]] · [[imap]]

(the owner, OR-26) A folder without a role from the source (no pointer, no server mark) is matched by name in one table of standard folder names in 10 languages. **One language per source**: the language with the most matching names wins (English on a tie) and only its names are used. No match: an ordinary folder. Used by IMAP folders without a mark and by both imports.
