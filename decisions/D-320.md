# Secondary sort: messages with the same value by when they were received
Topics: [[mail-window]] · [[storage]]

(the owner) **In every message list and every sort but Received, messages with the same value are ordered by when they were received**, newest first by default or oldest first, chosen in Settings > Message list > Secondary sort ("order by received, newest first" / "oldest first", lower case: the choice continues the label as a sentence). Kept on this computer only. Each sort has two sort indexes (index format 21), so every order reads an index alone ([[D-306]]). Why: ties came in the order the index was given them, random after a rebuild and in blocks per account in Favorites.
