# D-314 A folder is an object in the index
Topics: [[storage]]

(The owner) In the index a folder is a row with a unique id, the id of its parent and its display name, and each message holds the folder's id: a rename or a move of a folder, whatever the size of its tree, changes that one row, never a message. No id is kept outside the index: folders on disk and mail rules go by their names, and a rebuild gives new ids that serve the same purpose. An older index is upgraded in place at the first start: a short step in which it stays whole when interrupted, the rest afterwards in the background as with D-306.
