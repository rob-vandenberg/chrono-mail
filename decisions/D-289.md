# Advanced search is a search builder
Topics: [[mail-window]]

(the owner) **Advanced search is a search builder**: saved searches (Save, Save as, Rename, Delete, Reset); Where to search; "Find messages that match ALL/ANY of these conditions"; lines `Where/AND/OR [Anywhere, From, To, Subject, Body] contains [All, Any, This exact phrase, None of these words] [words] [+] [−]`; More... with Received first, then as [[D-288]]. A None line always leaves out; no brackets. Saved searches and the form last left: this computer only. Why: flexible, still plain.
