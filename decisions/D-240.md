# Undo and Redo on mail
Topics: [[mail-window]]

(B-18, the owner) **Undo and Redo of the person's actions on mail** (Ctrl+Z; Ctrl+Y or Ctrl+Shift+Z): each message back where it was, its marks, tags, notes and junk verdict as before. An undo is a new action, server first ([[D-193]]); a message changed since is left alone and told. Never undone: rules, the junk filter, timers, deletes for good, sending, a scheduled message made a draft.
