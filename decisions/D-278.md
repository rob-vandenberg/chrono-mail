# Import from a data file
Topics: [[importer]]

(the owner) Import from the office suite's mail program's data file (.pst). **After the import everything looks as it did in that program.** A data file named after a POP3 account here goes into that account's own folder tree; otherwise into Local Folders. Imported mail is never sent; IMAP mail never comes from a data file ([[D-193]]); only what can be imported is offered; nothing twice.
