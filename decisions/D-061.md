# Favorites order
Topics: [[mail-window]]

Favorites, in this order: All Inboxes, Unread, Outbox, Sent, Drafts, Flagged, Unreplied, Snoozed, Scheduled, Archive, Junk, Trash (Scheduled, Snoozed and Archive only once some mailbox has them, appearing in place). Then the accounts, Local Folders last. **The "Inboxes" section never comes back.**
