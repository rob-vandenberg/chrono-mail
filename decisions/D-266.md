# Paint what Qt asks, act instantly
Topics: [[changes-reach-the-screen]] · [[mail-window]]

(the owner) **The list paints exactly what Qt asks it to paint; it never replaces Qt's request with its own.** Every action that takes messages out of the list selects the next message below; after the last message of the folder nothing is selected, and a row is never selected before it is loaded and painted. The automatic repeats of a held key that piled up during an action are thrown away; a separate press is never thrown away. An action on many messages not done after 1 second says what it does in the status line; the busy bar moves only for work that has run for 1 second; an idle program uses next to no processor. Why: Delete must be instant, also with the key held.
