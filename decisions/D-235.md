# Attachments: left out only when shown
Topics: [[storage]] · [[mail-window]]

(the owner) **A part is left out of the attachments only when the text shows it** (the HTML text refers to it by cid:), whatever the sender labelled it. Attached pictures the text does not show are shown below it and stay attachments too (B-11). Why: a picture labelled inline in a plain-text message was shown nowhere.
