# Backup and Restore use .cmz
Topics: [[storage]]

(B-22, the owner) **Backup and Restore are Chrono Mail's own .cmz file** (Import and Export are for other programs): a ZIP of the chosen accounts exactly as kept here, passwords only in a protected backup (standard ZIP AES-256, a password the program makes). **After a restore everything is back exactly as the backup holds it**; the server still wins ([[D-193]]); exceptions: nothing is sent by itself ([[D-245]]) and Local Folders kept here ([[D-251]], [[D-265]]). Why: a backup must survive the loss of this computer and its key.
