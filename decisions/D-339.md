# Every colour of a Google calendar is a tag here
Topics: [[calendars-contacts-tasks]] · [[tags]] · [[basic-rule]]

(the owner) **A colour in Google Calendar is a tag: the same thing under another name.** So every colour of a Google calendar is a tag here, with the name the person gave it in Google, or Google's own name for the nearest of its eleven (Tomato, Banana, Grape…) when they named none. An appointment that carries such a colour carries that tag: in the calendar, in its window, and in the tag list with its number; an appointment that has tags of its own keeps only those, because its first tag gives it its colour ([[D-329]]). The tag lives where Google keeps it, never in the appointment and never as a category on Google; here it is kept in the index, which is never the truth. Taking the tag off in the window takes the colour off on Google, server first ([[D-193]]). Why: a colour that reaches the screen past the tags is a second, invisible way to colour an appointment, and the person could not find it back anywhere. Replaces the part of [[D-338]] that showed a name only for labels the person had named.
