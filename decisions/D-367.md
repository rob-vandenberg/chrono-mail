# A size slider for each view: Message list, Calendar, Contacts, Tasks
Topics: [[look]]

(the owner) **Settings > Appearance > Sizes has seven rows: Main window, Message list, Calendar, Contacts, Tasks, Other windows and dialogs, Text of messages. The Main window slider sizes the same parts in all four views (the top bar, the sidebar on the left, the status line); each view's own slider sizes everything to the right of the sidebar and below the top bar: in Mail the row with Sorted by, Filter and the count and the message list (the message text has Text of messages), in Calendar the row with Today and the calendar in every view, in Contacts and Tasks the list and the pane beside it. At the update the three new sliders start where the Main window slider stands, so nothing changes size until the person moves one.** Why: the owner wants the content of each view sized on its own, as the message list already was; the row above the list is part of the list for a person.
