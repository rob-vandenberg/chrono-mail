# Sizes and list choices shown live
Topics: [[mail-window]] · [[look]]

(the owner) Sizes are factors 0.75–2.00 on sliders, shown live; Cancel restores. **Settings > Message list's Layout, Reading pane, Dates, Row height, conversations, the tag's colour and the columns show at once too, and so do those of the Message list window**: tried without being saved; Cancel puts them back, OK saves. The reading pane gets back the size it had at a place when it returns there.
