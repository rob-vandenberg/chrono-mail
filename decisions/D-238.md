# Junk filter before the rules
Topics: [[mail-window]]

(the owner) **A junk filter runs on new Inbox mail before the rules**: mail the server marked as spam (X-Spam lines), or that the learned words make very likely junk, goes to Junk through the normal move (IMAP: server first). Never junk: contacts, people written to, senders a rule names. It learns from the person and from the server's verdict; never from its own guess. The words stay on this computer, encrypted. A switch per account.
