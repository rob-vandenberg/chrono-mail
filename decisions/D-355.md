# A reviewer brief per project
Topics: [[checks-and-tests]]

(the owner) **A project may have its own reviewer brief in its private folder**, `~/.claude/<project folder name>/reviewer-brief.md`; the hook that allows only the brief word for word uses it before the global one. Chrono Mail's names `DECISIONS.md` and its decision files as the requirements. Why: the global brief named Chrono Viewer's `REQUIREMENTS.md`, so every Chrono Mail reviewer looked for a file this project does not have.
