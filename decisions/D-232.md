# Standard folders come first
Topics: [[mail-window]]

(the owner) **Every standard folder comes before the person's folders**, in one order from one definition: Inbox, Unread, Outbox, Sent, Drafts, Flagged, Snoozed, Scheduled, Recovered, Archive, Junk, Trash; then the person's folders by name. Unread and Flagged keep their place when a folder before them is missing.
