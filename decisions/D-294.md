# An (i) explains a greyed option
Topics: [[mail-window]] · [[look]]

(the owner) **An option greyed for a reason gets an (i) right after its text**, never greyed itself and shown only while the reason holds: a hover shows the reason at once, a click opens it in a small window. While the (i) shows, the option has no hover text: one or the other, never both. Why: nobody hovers over something that looks switched off, so a reason only in a hover text is never found.
