# Undo and Redo of folders
Topics: [[mail-window]] · [[changes-reach-the-screen]] · [[imap]]

(B-18 step 2, the owner) **In Mail, Ctrl+Z also takes back Rename folder and Delete folder; Ctrl+Y or Ctrl+Shift+Z does them again.** They are in the same Undo list as the actions on messages, so Ctrl+Z undoes the last action whatever it was on. A renamed folder gets its old name back, with everything inside it. A deleted folder comes back where it was, with its subfolders, its messages, their marks and tags, and the rules its delete switched off. The menu names the folder ("Undo Rename folder “Projects”"), and the folder that comes back is selected. An undo is a new action, server first ([[D-193]]). A folder changed since, or one whose name is taken now, is left alone and told; a deleted folder can be brought back for 30 days ([[D-072]]). New folder and Empty folder are not undone ([[D-368]], [[D-240]]). Why: the owner's rule, "we do what we can to undo what he wants undone".
