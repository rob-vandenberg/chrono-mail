# Account column and fixed account
Topics: [[mail-window]] · [[storage]]

(the owner) **The Account column says which of the person's accounts received the message**, by the name the folder list shows. An account is fixed only when a message is retrieved from a server (the account that downloaded it) or sent (the sender's account); nothing else ever writes one. Once fixed it never changes. A message without a fixed account is shown by the rule, never written.
