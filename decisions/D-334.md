# One Tags block for every section
Topics: [[tags]] · [[mail-window]] · [[calendars-contacts-tasks]]

(the owner) **Mail, Calendar, Contacts and Tasks each have one Tags block below the folder tree, separate from it**, every tag in use with Mail's coloured tag and its number. A click on a tag turns its filter on, a second click (or Space, Enter) off; there is no "All …" line. The active line stays blue wherever the focus is, with a check mark in place of its number and the hover text "Click again to show everything"; the heading reads "Tags: <name>"; the tag stays while active, also when no item carries it. The filter applies to what the folder tree shows; in Mail it is the same filter as Filter > Tagged with. Mail gets Favorites > All Messages (every message), first in Favorites, before All Inboxes (the owner, 4.4.590), hidden and shown as every favorite; Contacts gets a tick box per address book, as Calendar and Tasks. Built in steps from 4.4.584. Why: a tag meant three different things in the four sections, and Mail's Tags entries could not be combined with a folder.
