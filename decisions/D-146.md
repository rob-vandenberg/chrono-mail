# An action changes only what it changes
Topics: [[changes-reach-the-screen]] · [[mail-window]]

**An action changes what it changes, and nothing else.** The engine tells every change as a fact after success (for IMAP after the server confirms); the list, the folder list and the other sections apply exactly that change; never a full reload after a local change. The window works by identity: an action takes the messages selected at the key press, a message under way is greyed and gets no second action, a refusal brings it back with the error. A message that changed where it is moves to the place the sort now gives it, its selection kept.
