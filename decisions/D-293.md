# Check for updates never on its own
Topics: [[packaging]] · [[security]]

(the owner) **Check for updates never connects on its own**: an installed copy looks on GitHub for the newest release only along with a Refresh that tried to reach a server, at most once a day, when Settings > General says so (on by default); About's Check for updates may connect itself. The file is checked against GitHub's fingerprint before Install. Why: the program must never reach the internet unasked.
