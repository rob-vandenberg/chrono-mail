# Only the refreshes act by themselves
Topics: [[pop3-smtp-sending]] · [[imap]] · [[importer]]

(the owner) **Only Refresh when the program starts and Automatic refresh send or receive by themselves**, for the accounts included in Send and Receive ([[D-059]]); never after a restore, an index rebuild, an import of POP3 mail or a Save in Edit account. A new account gets one first fill that only receives: nothing sent, deleted, made, moved or marked on the server, nothing removed here. Why: sending and deleting must never happen by themselves; an IMAP account without its server's data looks broken.
