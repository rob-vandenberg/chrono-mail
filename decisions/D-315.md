# D-315 Closing waits for no server
Topics: [[engine]]

(The owner) After Quit the window goes at once and the program ends, also when a server does not answer. Running commands get 3 seconds, with the window already gone. LOGOUT is said without waiting for the answer; a connection a command holds ends with that command. Mail checks and waits for new mail may be cut off when the process ends, as a crash would (4.1); the person's own commands (a send, a backup, a restore) are always waited for. Nothing on a server changes at closing and the Outbox stays as it is.
