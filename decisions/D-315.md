# D-315 Closing waits for no server
Topics: [[engine]]

(The owner) After Quit the window stays until the program has really finished: it is never hidden early, because that lies to the person. Every connection to a server is hung up, so what waits for a server gets a lost connection at once and ends by its normal path; no new connection is made. The update check is one of them, the name lookup is not. A send is never hung up, because a mail may never go twice: the mail being sent finishes until the server confirms it, the next one stays for the next start. Over 1 second the status bar says "Waiting for messages to be sent…" during a send, then "Shutting down…", and the busy bar moves.
