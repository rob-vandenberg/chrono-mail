# Keep both
Topics: [[calendars-contacts-tasks]] · [[sync-conflicts]]

(B-30, B-31, the owner) **Keep both**: an item changed on both sides becomes two; Chrono Mail's version a copy with a uid of its own, made on the server first (offline: here, sent later); the original takes the server's. A row's split keeps both entries of a field of several values; one entry on both sides is never split. Why: two persons' cards that met as one item; a change on the server is never written over.
