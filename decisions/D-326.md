# Which calendars the sidebar shows, and where new items go
Topics: [[calendars-contacts-tasks]] · [[mail-window]]

(the owner) **Settings > Sidebar has the tabs Mail, Calendar and Tasks**; on Calendar and Tasks the person ticks which calendars and task lists their sidebar shows; one left out is not in the sidebar, its items are not shown and it is never offered for new items, but stays in step with its server (this computer's view only). **A blue plus marks the calendar or task list new appointments or tasks go to** (hover: "New appointments go here"), moved with "Use for new appointments" in its right-click menu, never by unticking (a tick only hides or shows items for a moment); New, a double click and the editor start there; a read-only one is greyed in the editor of a new item. Why: people put appointments in the wrong calendar because nothing showed which one a new appointment goes to.
