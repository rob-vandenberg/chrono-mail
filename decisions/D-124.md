# Import everything without asking
Topics: [[importer]]

(the owner, UR-09) Menu > Import…; the program chosen in the window. **Everything mappable is imported as it is, without asking**; only the impossible is reported. The Outbox into Drafts (an import never sends); no duplicates; resumable by journal; no server is asked during an import. The mail export has one folder per store: an IMAP account's is never imported, a POP3 account's goes into its own folders with its marks and tags. Why: an export of Local Folders and an IMAP account was nested as Local Folders > Local Folders and the IMAP mail copied in.
