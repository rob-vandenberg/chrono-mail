# One window to add any account
Topics: [[pop3-smtp-sending]] · [[calendars-contacts-tasks]]

(UR-04, the owner) **Every kind of account is added in one window**, Add an account: its Account type offers POP3, IMAP, CalDAV and CardDAV. In Link to, a mail account chosen there is linked with the same server and the same login; anything else is a separate account. Why: a second window elsewhere was so confusing it counted as a bug; either the same account or not, never a mix.
