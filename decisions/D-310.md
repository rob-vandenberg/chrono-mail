# Calendar messages in mail (iTIP)
Topics: [[calendars-contacts-tasks]] · [[mail-window]] · [[basic-rule]]

(The owner) **Chrono Mail supports every calendar message a mail can carry** (RFC 5546, RFC 6047; journal entries later, B-32): a mail holding one shows a card above its text, alone when the text shows nothing, never a white page, and the calendar part is not offered as a file. Answers go to a calendar the person picks (that of the receiving account first); per account the person ticks "Send confirmation emails via" with Chrono Mail or the server: unticked nothing goes out; greyed only when certain: a server tested to send them whatever it is told (Kerio) leaves no choice, no calendar server means Chrono Mail; any other server that announces it is told SCHEDULE-AGENT=CLIENT when it should stay silent; when the server cannot answer (another address, a meeting that never reached it) Chrono Mail sends. Why: the program never shows less than the mail holds, and the organizer never gets two answers.
