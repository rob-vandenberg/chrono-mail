# Calendar messages in mail (iTIP)
Topics: [[calendars-contacts-tasks]] · [[mail-window]] · [[basic-rule]]

(The owner) **Chrono Mail supports every calendar message a mail can carry** (RFC 5546, RFC 6047; journal entries later, B-32): a mail holding one shows a card above its text, alone when the text shows nothing, never a white page, and the calendar part is not offered as a file. Answers go to a calendar the person picks (that of the receiving account first); whether the server or Chrono Mail mails the answer is chosen per account, as the server announces (Kerio sends them itself and ignores SCHEDULE-AGENT=CLIENT). Why: the program never shows less than the mail holds, and the organizer never gets two answers.
