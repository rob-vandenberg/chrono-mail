# Templates and signatures: one library, chosen per account
Topics: [[mail-window]]

(the owner) **A template and a signature are the same thing, a named text; Settings > Templates and Signatures holds the library and, below it, per account the texts it puts in by itself.** The library: the texts in the person's order, the first seven with Ctrl+1 to Ctrl+7, New, Edit, Delete, ↑, ↓, a preview beside it behind a splitter, Open…/Save As… (one .html) and Import…/Export… (all texts in one file of Chrono Mail's own). Per account: a template and a signature for new mail, replies and forwards ("Not selected" for every account to start with) and the signature position. In a message: one signature; the bar's Signature button puts a text in as the signature or replaces it, its Template button and Ctrl+1 to Ctrl+7 add a text at the cursor ([[D-363]]); From swaps a default one; New's menu starts a message from any text. Kept at OK, on this computer only (D-201). Why: a user's complaint, and one fixed signature per account is far less flexible than a library with keys.
