# The status line after a failed mail check; Ctrl+Shift+O for the Operations window
Topics: [[look]] · [[pop3-smtp-sending]]

(the owner) **When a mail check fails for one account, the status line names that account and its error; when it fails for more accounts, it gives each error once with the number of accounts, without names. A click on that error line opens the Operations window at its Errors tab, and Ctrl+Shift+O (a key the person can change) opens the Operations window from anywhere in the main window. A server whose name could not be looked up says "The server's name could not be found (no internet connection?)" (mail and calendar servers) or "Google could not be found (no internet connection?)" (Google), in the status line and the Operations window, never the system's text.** Why: the same error of 11 accounts filled the line 11 times with "Connection failed: getaddrinfo failed", which named no account and meant nothing to a person.
