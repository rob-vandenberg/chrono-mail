# Sent by one path, once
Topics: [[pop3-smtp-sending]]

(RV-109 and the rest of batch 1) **A message in the Outbox is sent by one path only, once**: every send holds the Outbox lock from storing its copy until the server answered; a message the server took is never sent again, also when its move to Sent failed or the server dropped the goodbye. Once the server took a message, nothing after it makes it a failed send: a failure there is a warning. Why: five ways sent the same mail twice.
