# A restore never deletes POP3 mail
Topics: [[pop3-smtp-sending]] · [[storage]]

(batch 3, RV-61) **What a POP3 account downloaded never names a message a restore did not bring back.** A message left out is downloaded again: twice at worst, never deleted on the server. A damaged part of a backup is left out and told, the rest comes back. Why: a named message that is not here is deleted on the server by "delete from the server when deleted here".
