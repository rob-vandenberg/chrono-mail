# A file's extension is never made up
Topics: [[mail-window]]

(The owner) **The extension of an attachment comes from the name the mail gives it, or from Chrono Mail's own fixed list of types it knows for certain** (text/calendar is .ics, a contact card .vcf), never from the computer's own list; a part without a name of an unknown type gets none ("attachment-1"). Why: "the application should never make up information"; an invitation was .bin on one computer and .ics on another.
