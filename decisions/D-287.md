# Three places to search
Topics: [[mail-window]]

(the owner) **A search looks in one of three places, in this order: This folder only, This folder + subfolders, All folders**; All folders at every start. All folders means every folder of every account, also from a Favorites or Tags view: Junk and Trash too; the filters the person chose still apply. In a search of several folders each message acts as in the folder it lives in. A selection is in principle single actions. Only while a search is shown; a local read, nothing on a server.
