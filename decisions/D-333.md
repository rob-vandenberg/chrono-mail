# The starting tags
Topics: [[tags]]

(the owner) **At the very first start of Chrono Mail on a computer (no settings folder and no data folder yet) the tag list gets eleven tags, the palette colours under their names: Tomato, Flamingo, Tangerine, Banana, Sage, Basil, Peacock, Blueberry, Lavender, Grape, Graphite, shown in every section.** Never for someone who already uses it, never over tags a person has. Why: no standard list of tags exists; a generic list in distinct colours is a start the person renames.
