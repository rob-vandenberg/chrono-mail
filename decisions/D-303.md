# One action per message
Topics: [[mail-window]]

(the owner) **An action on a selection is, in principle, one action per message**: each message goes or changes only if the person could do that to that one message by itself; otherwise that message stays and the others still go, and the status line says what stayed and why. The work is still done in batches (one per account and folder). Why: "There is no 'move 2 messages together'… that is 2 actions moving 1 message"; this settles every mixed selection.
