# No personal detail in the project
Topics: [[way-of-working]] · [[checks-and-tests]]

(the owner) **No personal detail in the project folder or on GitHub**: no account address, server or computer name, network address, password or mail detail; only the owner's name, email and the GitHub address. Neutral words in the documents, made-up data in tests; `gitpush.sh` scans every file and the message and refuses on a match.
