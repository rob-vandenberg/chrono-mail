# Tray click on Wayland
Topics: [[mail-window]]

**Wayland never says a window is minimized**, so there a tray click hides Chrono Mail only while its main window, or a dialog waiting for an answer, has the focus; otherwise it brings the window back and to the front. X11 and Windows unchanged. Why: the first click on a minimized window hid it, and a second start could not bring it back.
