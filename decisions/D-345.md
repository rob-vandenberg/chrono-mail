# Accounts shown alike are told apart by their sign-in name
Topics: [[pop3-smtp-sending]] · [[look]]

(the owner) **When two accounts would be shown with the same name, each gets its sign-in name and kind added**, as "Rob - robvandenberg64@gmail.com (Calendars and contacts)"; the server is added only when the sign-in name is the name itself, or another account shown alike has the same sign-in name and kind. Why: "The enduser has NO idea what apidata.googleusercontent.com means and will think it is an error." Replaces the server part of [[D-184]].
