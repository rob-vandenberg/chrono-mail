# Reading pane header has one height
Topics: [[mail-window]]

(the owner) **The reading pane's header has one height for every message when it opens**: to and cc with the names that fit then +N more, the subject on one line with …, the attachments that fit then +N more; a click on +N more grows it. Why: a header of another height moved the old message text before the new one was painted; the web engine gives no signal when a page is on screen, so no waiting can fix it.
