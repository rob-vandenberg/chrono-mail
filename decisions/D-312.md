# D-312 The appointment window
Topics: [[calendars-contacts-tasks]]

A saved appointment opens read-only; Edit makes it the editor. Attendees show names when known and change in a dialog; tags are picked from a list; the location has several lines. The repeat list follows the event's date and Custom writes the standard rule, keeping what the Custom window does not show. The fifth weekday of a month repeats as its last. One date with start and end time, a second date under Several days; moving the start moves the end by the same amount. New and a double click in month view start All day. Toolbar and menu Edit go straight to the editor.
