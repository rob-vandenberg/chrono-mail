# D-312 The appointment window
Topics: [[calendars-contacts-tasks]]

(the owner, 4.4.576) **An appointment opens ready to change**: a double click, Enter, Edit… in its menu, the toolbar's Edit and the Tag overview all open the window with Save and Cancel; a repeating one asks this date or all of them first. One of a read-only calendar opens only to read, with the reason and Close; a Cancelled one opens once it is Restored. Why: a read-only first step with an Edit button (copied from another calendar) only cost a click. Attendees show names when known and change in a dialog; tags are a list ([[D-329]]); the location has several lines. The repeat list follows the event's date and Custom writes the standard rule, keeping what the Custom window does not show. The fifth weekday of a month repeats as its last. One date with start and end time, a second date under Several days; moving the start moves the end by the same amount. New and a double click in month view start All day.
