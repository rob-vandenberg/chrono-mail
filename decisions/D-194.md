# Items go to the server first
Topics: [[calendars-contacts-tasks]] · [[sync-conflicts]]

(R-23, R-24, the owner) **Appointments, tasks and contacts go to the server first** and change here only when it took them; offline, done here and sent at the next sync. An item whose visible fields changed both here and on the server since they last agreed is a sync conflict as a whole, every visible difference the person's choice; changed on one side only it is a delayed update. A lasting refusal of a change made offline, changed on one side and deleted on the other, a refused delete: a sync conflict too; the Sync conflicts window settles them. A group's members and the tags are each an entry by itself and never make a conflict. Which fields can clash: [[D-308]]. Why: Chrono Mail cannot know which side is right; a group is a jar of pebbles, one put in on each side both go in.
