# The message window shows Reply, Reply all and Forward with their text
Topics: [[mail-window]]

(the owner) **In the window of one opened message, Reply, Reply all and Forward show their text beside the icon, as in the main window's bar; Forward has no arrow there** ("Thos 3 buttons need text next to them like this"; Q81: "No, text only"). Why: an icon alone does not tell an unknowing user what it does (OR-17).
