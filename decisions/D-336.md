# The Add an account window in tabs
Topics: [[mail-window]] · [[look]]

(the owner) **The Add an account window shows its mail part in three tabs: Account (the names, the address, the incoming user name and password), Servers and Options**, with Account type at the top and the result line and buttons always below the tabs. Gmail needs only the Account tab; Servers and Options are greyed for it with the reason. The window is never taller than its screen, the window manager's title bar counted. Edit account keeps its own layout (the login with each server, [[D-186]]). Why: on the owner's screen the one-page window cut off its buttons for every account type.
